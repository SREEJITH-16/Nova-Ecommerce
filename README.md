# NOVA

Premium e-commerce storefront. Vanilla HTML, CSS and JavaScript, no build step.

## Features
Hero, categories, 25 products, live search, filters and sorting, quick view, product pages,
wishlist, cart drawer, 4-step checkout, order confirmation, dark mode, client-side routing
(`pushState`), and localStorage persistence.

## Structure
```
index.html   css/style.css   js/app.js   404.html   vercel.json   _redirects
```

## Run locally
Routes like `/shop` need a server that falls back to `index.html`:
```
npx serve -s .
```

## Deploy
- **Vercel:** import the repo, framework "Other", no build command. `vercel.json` handles routing.
- **Netlify:** publish directory `.`, `_redirects` handles routing.
- **GitHub Pages:** works from the repo root. `404.html` is a copy of `index.html` so deep links load.
  Pages serves from `/<repo>/` for project sites, so use a custom domain or a `<user>.github.io` repo
  (asset paths are absolute: `/css/style.css`).

Product images are original studio-style SVG renders in `assets/images/p<id>.svg` (generated by `art()` in `js/app.js`, which also serves as a fallback if a file fails to load). To use real photography, drop files into
`assets/images/` and keep the same names.
